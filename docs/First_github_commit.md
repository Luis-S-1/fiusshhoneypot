set default branch to main:
git config --global init.defaultBranch main

initialize git in the relevant directory

git init       [INSIDE the DIRECTORY you want to track]

IF you need to rename the branch
git branch -m main


ADD all the files to git rep:
git add .

git commit -m "first commit to fiusshhoneypot repository"


Uploaded to github:

git remote add origin https://github.com/Luis-S-1/fiusshhoneypot.git

git branch -M main         [if needed. This sets branch to main]
